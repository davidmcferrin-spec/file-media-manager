MEDIA MANAGEMENT  
 File and Folder structure 
Key Points 

Consistent and rigid adoption of this policy

Find files fast. You should not need more than 3 clicks to open what you need.

No spaces in names. Use the underscore line “_” instead – ex: My_File NOT My File

All file names should stand alone and descriptive of where the file came from or should be placed 
Dates and Times

Dates should always be YYYYMMDD and time 24-hour time is HHMM Eastern

Date Ex:

20251002

Time: HHMM (24-hour clock, Eastern Time)

Example: 0700 = 7:00 a.m.

Example: 1300 = 1:00 p.m. 
Dictionary file (README.txt):

ALL show/franchise/series abbreviations WILL be kept in a README.txt dictionary at the root of the drive. ALL classes WILL be described and purposefully explained in the same README.txt keep at the root of the drive

Nothing should be added to classes lightly, each class should be purposeful, unique, and deliberate… no gray area / no overlap.

Always keep this file updated

Folder order (always 3 levels deep):

Show name (show/franchise/series abbreviations)

Year and month (YYYY_MM)

Type of media (Clean, Program, ISO, RAW, etc.)

NY Ex:   /CUOMO/2023/05/ISO → Show Cuomo, May 2023, ISO files

CHI Ex: /NNN_Chicago/2024/08/Program → NewsNation Now Chicago, August 2024, Program files 
All Files Should Be

Example: MIA_20251002_0700_CLEAN

ISO/GISO will get an additional field before the file extension for guest name

OB_20240711_1300_GISO_Bill_Orilley.mxf

OB = On Balance

20240711 = 2024 Year 07 Month 11th Day

1300 = 1:00pm eastern time

GISO = Guest ISO

Bill_Orilley = Bill O’Reilly

mxf = File Extension

We know this file should go in /OB/2024/07/ISO folder
